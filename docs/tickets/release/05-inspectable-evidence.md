# 05 — 读者可展开关键事实的原文依据

**状态：** implementation-complete；真实正式期刊逐条审阅待 #2 的实际模型运行。

**GitHub：** https://github.com/voidforall/ai-newspaper/issues/5

## 交付行为

读者从每条新闻的重要数字或结论展开到对应出处与短摘录，看清哪些是来源陈述、编辑判断或仍未知。

## 阻塞依赖

02、03。

## 验收条件

- [x] 文章至少将影响读者判断的关键断言关联到来源 URL、短摘录/定位与抓取时间；既有期刊仍能打开。
- [x] 证据入口在新闻中可用键盘/触屏展开；来源事实、厂商主张、社区体验和编辑判断使用清楚标签。
- [x] 无材料支持的结论删除或明确标记未知；完整性检查阻止引用不存在的证据 ID，不能把这种检查宣传为事实核验。
- [x] 人工审阅对照最终摘要/背景/影响，避免一处说资料缺失、另一处却给出该资料；保存一个跨块矛盾样例作回归。
- [ ] 通过至少一份真实期刊逐条抽查证据关系；不公开完整抓取原文，不让来源文本改变编辑指令。

## 范围边界

只做少量关键事实和必要数据字段；不建知识图谱，也不显示伪精确的模型置信分。
