## 验收条件

- [x] 配置一个主 recipe，包含可靠的一手/技术来源、目标受众、中文输出、最多八条的篇幅上限和来源/主题上限。
- [x] 候选进入选稿前规范化 URL 并合并重复出处，保留有意义查询参数；选稿后不因重复候选白白丢失名额。
- [x] AI 依据技术实用性、新增事实、证据质量和受众相关性选择；非 AI 路径不直接比较 HN points 与 RSS 的位置分数。
- [x] 论文明确结果与限制；release 说明可用性/兼容影响；新闻说明实际影响，不用热度代替重要性。
- [x] 用混合来源、重复 URL、营销内容和不足五条有效候选的样例核查结果；不为凑数补无价值故事，期刊显示实际栏目。

## 范围边界

首发不要求语义去重全覆盖、双语同步或大量空栏目；最低篇数不是硬性填充目标。
