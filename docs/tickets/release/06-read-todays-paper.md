## 验收条件

- [ ] 首页优先展示最新已发布主刊，明确日期/更新时间和一句话定位；没有当期时诚实展示上一期。
- [ ] 每条新闻有不依赖展示标题的稳定永久链接，包含原文出处；旧期刊路径和归档入口保持可用。
- [ ] 主版呈现有限摘要，深读内容按需展开，证据入口与键盘焦点可见。
- [ ] 在 375/390 像素手机与桌面检查长标题、长 URL、中文段落、空态和旧档案；无横向溢出或被固定导航遮挡。
- [ ] 无需配置或注册就能读 demo；配置自己的 recipe 作为独立次级入口。

## 范围边界

沿用现有报纸语言；不引入账号、收藏、全文搜索或全面设计系统迁移。
