## 验收条件

- [x] 先复现现有空配置生成路径，证明占位/提取文本如何进入正式期刊。
- [x] 期刊记录 schema 版本、生成时间、编辑方式和 draft/published 状态；旧期刊兼容读取，不冒充重新审核过。
- [x] 缺配置、超时、无效输出均产生可辨认失败信息和草稿；草稿不进入首页、归档导航或分发，失败不覆盖上一份正式期刊。
- [x] 网络调用有超时和有界重试；运行摘要记录来源状态、模型、耗时和实际可得 usage，不记录密钥或编造成本。
- [ ] 用模拟失败验证安全行为；维护者配置凭据后完成至少一次真实生成，并核查实际模型输出与刊物一致。

## 范围边界
