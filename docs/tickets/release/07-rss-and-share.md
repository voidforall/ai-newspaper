# 07 — 从同一正式期刊生成 RSS 与可传播分享预览

**状态：** implemented；RSS、PNG 封面和子路径 HTTP 抓取验收通过。

**GitHub：** https://github.com/voidforall/ai-newspaper/issues/7

## 交付行为

读者能订阅主刊，也能分享一条新闻或整期报纸，接收方看到清晰预览并回到对应内容。

## 阻塞依赖

02、06。

## 验收条件

- [x] 页面有可发现的 RSS 入口，feed 只包含正式期刊，使用稳定 ID、正确链接、发布时间和有效 XML。
- [x] 新闻永久页与期刊页有正确的绝对 canonical URL、标题、描述、OG 图片和必要分享元数据。
- [x] 分享封面显示日期、标题和站点地址；不是只有模板报头，也不把不完整抓取内容当简介。
- [x] 网页、feed 与分享描述来自同一正式期刊快照，草稿和失败重试不会泄漏或重复订阅条目。
- [x] 在带仓库子路径的 Pages 构建中检查图片、feed、新闻链接实际可访问；用本地元数据抓取核验预览所需信息。

## 范围边界

不接邮件/IMAP、微信、通知平台或复杂 PDF 引擎；OG 图采用确定性静态生成。
