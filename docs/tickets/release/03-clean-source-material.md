## 验收条件

- [ ] 先从调研发现的线上期刊走到其原始页面，保存可重复的污染、提取失败和正常材料样本。
- [ ] 对新闻正文采用经过样本对照的提取方式；GitHub/arXiv 优先使用可信的结构化项目/摘要材料。
- [ ] 原文不可用时，只使用明确标记来源的可信 feed 材料，或跳过并记录原因；不填充通用占位句。
- [ ] 保留真实来源发布时间、抓取时间、材料 URL 和提取状态，查询日期不充当真实发布时间。
- [ ] 从样本输入到成品草稿做端到端检查：无广告/导航污染，重要限定条件可供编辑使用，来源链接完整。

## 范围边界

先修已观察到的页面类型；不做通用浏览器爬虫、全文镜像或全文公开归档。
